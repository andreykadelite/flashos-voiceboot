# FlashOS 2026.10.13.2 и установщик 1.0.8

[English](../en/release-2026.10.13.md) · [Главная](../../README.md)

Этот выпуск заменяет FlashOS 2026.09.12.1 с установщиком 1.0.4. Главное
добавление — магазин приложений Debian. Теперь на флешке можно хранить
установленные программы и их настройки, а внешние окна озвучивать через Orca.

## Магазин и приложения

Откройте «Приложения» → «Магазин приложений Debian». При первом запуске
выберите размер хранилища: 2, 4 или 8 ГиБ. Для него нужно свободное место
на основном разделе флешки. Программы, документы и настройки записываются
в `flashos/applications/store.ext4` и сохраняются после выключения.

В магазине есть поиск, вкладки доступных и установленных пакетов,
обновления и выбор официального источника Debian 13 или Backports.
Перед изменением пакетов FlashOS показывает весь план, зависимости
и требуемое место. Подписи репозиториев проверяются. Если интернет пропал,
можно перейти в сетевые инструменты, подключиться и явно повторить загрузку.
Уже установленные программы и сохранённый каталог доступны без интернета.

Приложения запускаются от отдельного пользователя в своей Debian-среде.
Orca читает окна программ, которые поддерживают AT-SPI. Поддержка экранного
диктора у разных приложений различается. Ctrl+Alt+Escape завершает внешнюю
сессию и возвращает в меню FlashOS.

## Сеть и речь

Добавлены сохранённые профили Ethernet и Wi-Fi: автоматические и статические
IPv4/IPv6, DNS, маршруты и прокси. Привязка к компьютеру и адаптеру помогает
не применить чужой статический адрес. При ручной смене сети есть подтверждение
с таймером и возврат к прежнему подключению. Пароли Wi-Fi и прокси хранятся
в зашифрованном файле, который открывается общим паролем пользователя.

В «Утилитах» можно настроить голос Orca, размер текста, контрастность,
анимацию и указатель. Orca по умолчанию следует речи FlashOS; при желании
можно выбрать отдельный голос. Обе среды используют пять голосов RHVoice
и русский eSpeak NG. Длинные вводные реплики FlashOS можно прервать F7,
Enter или пробелом. Пропуск реплики не подтверждает следующее действие.

Обновлён аппаратный набор: ядро, прошивки, SOF, Mesa и микрокод процессоров.
Установщик сохраняет автономную установку одним EXE и проверяет встроенные
файлы по SHA256. Его упаковка позволяет Windows загружать небольшую
исполняемую часть отдельно от большого системного комплекта.

## Скачать и установить

Для подготовки флешки в Windows скачайте `FlashOS-Setup.exe` и
`SHA256SUMS.txt` из [релиза](https://github.com/andreykadelite/flashos-voiceboot/releases/latest).
Сверьте контрольную сумму:

```powershell
Get-FileHash .\FlashOS-Setup.exe -Algorithm SHA256
```

Установка удаляет разделы и файлы выбранной флешки. Сначала сохраните
нужные данные на другом носителе. После установки скопируйте свои ISO
в папку `iso`. Подробные шаги находятся в [инструкции установщика](installer.md).

Если на флешке уже есть приложения, перед переустановкой сохраните весь
`store.ext4`, ISO, документы и настройки с обоих разделов. Переустановка
через EXE удаляет прежнее хранилище. [Что копировать](guide.md#голос-питание-и-сохранение).

## Системный архив для сборки

Системный ZIP превышает лимит одного файла GitHub Releases, поэтому
опубликован двумя частями. Они нужны разработчику, который собирает EXE
из исходников. Для обычной установки достаточно готового EXE.

Скачайте в одну папку `FlashOS-2026.10.13.2-system.zip.001`,
`FlashOS-2026.10.13.2-system.zip.002`, `system-archive-parts.json`
и `join-system-archive.py`. Python 3.11 или новее соберёт ZIP и проверит
SHA256 каждой части и готового файла:

```sh
python join-system-archive.py system-archive-parts.json
```

Сценарий не заменяет существующий ZIP. При ошибке проверки незавершённый
результат удаляется, исходные части сохраняются. Распакуйте проверенный ZIP
в корень исходников этого же тега: он создаст дерево `dist`.
Это архив файлов для сборки, а не загрузочный ISO.

## Проверки и ограничения

В проекте сохранены результаты автоматических тестов, испытаний магазина,
сети и речи в QEMU, а также проверки запуска собранного EXE. Точный хеш
установщика и состав проверок находятся в `FlashOS-Setup.verification.json`
из этого релиза. [Подробный отчёт](testing.md) отделяет текущие испытания
от результатов прежних сборок.

Для текущего выпуска не проводились запись на физическую флешку,
перезагрузка физического ПК и проверка Windows 10. Первый запуск
с Secure Boot может потребовать регистрации ключа Ventoy на экране
прошивки без озвучки. EXE пока не имеет подписи издателя.
